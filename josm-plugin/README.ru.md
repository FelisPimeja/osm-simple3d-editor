# simple3d — модуль JOSM для 3D-редактора Simple3D

[English](README.md)

Связка [JOSM](https://josm.openstreetmap.de/) и [OSM Simple3D editor](https://felispimeja.github.io/osm-simple3d-editor/) —
браузерного редактора 3D-зданий ([Simple 3D Buildings](https://wiki.openstreetmap.org/wiki/Simple_3D_Buildings))
и планов этажей. Работайте в JOSM как обычно, а высоты, крыши, части зданий и этажи правьте в 3D на тех же данных:

- **Одни данные.** Редактор показывает активный слой данных JOSM вместе с несохранёнными правками и подхватывает
  изменения в JOSM за секунду.
- **Правки сразу в JOSM.** Каждая правка в 3D становится командой JOSM с именем по сути правки («3D: …»).
  Она видна в истории JOSM и уходит в OSM вместе с остальными правками при отправке из JOSM.
- **Общая отмена.** Ctrl+Z в редакторе или в JOSM отменяет последнюю команду, где бы она ни была сделана.
- **Общее выделение.** Выбрали здание в JOSM — оно выделено в 3D, и наоборот.
- **Без отдельного входа.** Редактор показывает пользователя JOSM; отправка в OSM — из JOSM.

## Установка

**Из JOSM:** Настройки → Модули → найти `simple3d` → отметить → OK, затем перезапустить JOSM
(если в списке его нет — сначала «Загрузить список»).

**Вручную:** скачать [simple3d.jar](https://github.com/FelisPimeja/osm-simple3d-editor/releases/latest/download/simple3d.jar)
в папку модулей JOSM и включить в Настройки → Модули:

| Система | Папка |
|---|---|
| macOS | `~/Library/JOSM/plugins/` |
| Linux | `~/.local/share/JOSM/plugins/` |
| Windows | `%APPDATA%\JOSM\plugins\` |

Нужен JOSM 19613 или новее.

## Как пользоваться

Загрузите данные в JOSM и выберите **Вид → Open in 3D editor (Simple3D)** (Ctrl+Alt+Shift+3) — редактор откроется
в браузере над текущим видом карты.

Страницу отдаёт сам модуль по адресу `http://127.0.0.1:8112/editor/` (копия сайта редактора), поэтому всё работает
в любом браузере, включая Safari. Модуль слушает только `127.0.0.1` и отвечает только страницам редактора: другие
сайты не могут читать или менять ваши данные в JOSM.

Без модуля редактор тоже может читать слой JOSM — через Remote Control, но только читать: правки не возвращаются
в JOSM, нет общей отмены и выделения.

## Настройки

Расширенные настройки JOSM (Настройки → Расширенные):

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `simple3d.port` | `8112` | Локальный порт модуля |
| `simple3d.url` | сайт редактора | Откуда берётся страница редактора |
| `simple3d.proxy` | `true` | Открывать редактор через модуль; `false` — прямо с сайта (Chrome, Firefox) |
| `simple3d.origins` | пусто | Ещё сайты (origin через запятую), которым можно обращаться к модулю |
